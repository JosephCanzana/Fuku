About Fuku

A spaced-repetition flashcard app that uses the SM-2 algorithm.

Why I built it

I struggled with creating reviewers. Then I found out that you can generate flashcards with AI, optimize the prompt to get good cards, and review them in a third-party app. That made me wonder: what if one app made the whole process frictionless? Fuku is that app.

Features

Review cards using the SM-2 algorithm
A learning state for new cards
Cards organized per deck, with tags
Create your own flashcards
Generate flashcards with AI
Exam or general generation mode
Import and export flashcards via CSV

How it's built

Django PostgreSQL Tailwind CSS JavaScript HTML Docker Gemini API (free tier)

Design decisions

  • New cards go through a learning state instead of being scheduled in days right away.
  • The app uses the free Gemini API, so generation is limited to 20 cards and 5,000 characters of text for now.
  • This is an MVP, built within a limited time frame.

Challenges and what's next

The hardest parts were CSV import and export, because the files have to be parsed carefully, and the AI generation, because the prompt has to be good for the cards to come out accurate.

  • A better design and UI, with more themes and customization
  • Forgot-password emails
  • Direct import of presentations, docs, PDFs and text, converted into flashcards
  • A docs and PDF reviewer
  • Search and filters
  • A progressive web app
